# このツールについて

メセタ帳（Meseta Ledger）は、PSO2 NGS（PC版）が書き出す公式ログを読むための、非公式・個人・非営利のファンメイドツールです。

本ツールは非公式のファンメイドツールです。株式会社セガとは関係ありません。

PHANTASY STAR ONLINE 2 NEW GENESIS  
（C）SEGA

公式サイト: https://pso2.jp/players/

ゲーム内の画像やアイコンは同梱していません。パケットの解析、メモリの読み取り、クライアントファイルの展開、ゲームの自動操作はしません。データの入口は、PC版の公式ログファイルと、将来足す手入力だけです。

ライセンスはまだ決めていません。
