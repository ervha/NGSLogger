# プライバシー

- ログは外部へ送りません。Web版はブラウザの中だけで処理します。通信するのは、公開したあとのアプリ本体の読み込みと、将来 zip 版でオプトインにする「新しい版の確認」だけにする予定です。
- このひな形の画面は、選んだファイルの種別と ActionLog の行数だけを表示します。ログの本文は画面に出しません。
- ChatLog と SymbolChatLog は読みません。種別を決めるため、先頭数行のチャンネル名（と、シンボルチャットかどうかの判定に必要な短い本文）だけを見て、残りは破棄します。チャット本文を保存する機能は作りません。
- 自キャラクターの ID と名前も、パース結果には残しません。保存するようになったらハッシュだけを置き、画面では自分で付けた表示名を使います。
- アクセス解析や広告のタグは入れません。
- Web版のデータはブラウザの中にあります。サイトデータを消すと、将来保存する集計も消えます。消える前に書き出せるようにするのは、この次の段階です。
