# プライバシー

- ログは外部へ送りません。Web版はブラウザの中だけで処理します。通信するのは、公開したあとのアプリ本体の読み込みと、将来 zip 版でオプトインにする「新しい版の確認」だけにする予定です。
- この画面は、選んだファイルの種別と ActionLog の行数を表示します。ログの本文は外部へ送信しません。
- **チャット履歴の読み取りはオプトイン（初期値オフ）です**:
  - 既定（オフ）では、種別を決めるために先頭数行のチャンネル名だけを見て、本文は読み込まず破棄します。
  - チャット履歴の遡り確認を有効にしたい場合のみ、画面のチェックをオンにすることでローカルメモリ上で ChatLog の本文をパースし、一覧で確認・検索・ソートできるようになります。このデータも外部サーバーへ送信されることはありません。
- 自キャラクターの ID と名前も、メセタ集計のパース結果には残しません。保存するようになったらハッシュだけを置き、画面では自分で付けた表示名を使います。
- アクセス解析や広告のタグは入れません。
- Web版のデータはブラウザの中にあります。サイトデータを消すと、将来保存する集計も消えます。消える前に書き出せるようにするのは、この次の段階です。
