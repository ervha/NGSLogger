## いま動くこと

- UTF-16LE（BOM あり・なし）のデコードと、チャンクの境界で文字や行が割れない処理
- 中身による種別判定（ActionLog / RewardLog / ScratchLog / 通貨系 / ChatLog / SymbolChatLog / 未対応）
- ActionLog のパース（SetValue 行の列ずれ、金額行、`[DiscradExchange]` の綴り）
- 合成ログでのマイショップ購入、NPC 購入の差分、売却推定のテスト（最大40件の枝刈り探索）
- **高速差分キャッシュ & 永続化（IndexedDB）**:
  - ファイル名・ファイルサイズ・設定ハッシュをキーとしてパース結果を自動キャッシュ。
  - 大量ログ（数十〜数百ファイル）の再ロードが瞬時に完了。
  - 公式ログフォルダ（`Documents\SEGA\PHANTASYSTARONLINE2\log_ngs` および `log`）を自動検知して優先適用。
- **メセタ収支 & プレイ分析ダッシュボード**:
  - **KPI表示**: 純利益・総収入・総支出・マイショップ売上受取額（および手数料引かれ額）
  - **収支推移グラフ**: 日別収支（収入・支出・純利益）のバー・ライン複合グラフ（ECharts）
  - **収支カレンダー（ヒートマップ）**: 月間グリッド表示で黒字・赤字・日別純利益を直感的に視覚化
  - **セッション別時給計測**: ログイン〜ログアウトのプレイ間隔を自動判定し、プレイ時間とメセタ時給（N-メセタ/h）を自動算出
  - **売れ筋アイテム分析**: マイショップ売却推定ログから販売個数・総売上・平均単価をランキング集計
  - **日別収支内訳テーブル**: 換金、ショップ購入、NPC購入等の詳細内訳
- **チャット履歴の遡り確認（オプトイン）**:
  - 初期値はオフ（プライバシー保護）。トグルをオンにすることで ChatLog を解析。
  - チャンネル絞り込み・キーワード検索・日時順ソート。
  - **注目ワード強調 & 絞り込み**: プレイヤー名や募集単語をカンマ区切りで登録し、該当発言のハイライトおよび「★注目ワードのみ」絞り込み。
- **CSV エクスポート**:
  - 日別収支、セッション時給、売れ筋ランキング、チャット履歴を Excel 対応（UTF-8 BOM付き）CSV でワンクリック保存。
- **ゲームプレイ用ミニウィジェット（コンパクト表示）**:
  - 当日純利益や直近時給をコンパクトに常時表示できるミニ画面モード。
- **ポータブル版でのログフォルダ自動読み取り & リアルタイム監視**:
  - 選択したログフォルダのパスを記憶し、次回以降起動時に自動スキャン＆読み込み。
  - プレイ中のログ追記を軽量スナップショットで自動検知して画面を同期。
- **データのバックアップ保存・復元**:
  - 現在の集計結果と設定を JSON ファイルとしてワンクリックでエクスポート / インポート。
- GitHub Pages による Web 版の自動公開（main へのプッシュで自動デプロイ）
- GitHub Releases による Windows デスクトップ版（単体ポータブル exe および zip）の配布ワークフロー
